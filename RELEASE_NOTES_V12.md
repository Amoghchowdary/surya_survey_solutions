# Surya Survey Solutions V12

## Scope
Production responsive correction using the user-provided desktop/mobile comparison as the reference.

## Desktop
- Existing approved desktop composition is preserved at 1200px and above.

## Tablet
- Keeps the same hero hierarchy with proportionally scaled typography and dedicated tablet imagery.
- Four trust cards remain in a single row.

## Mobile
- New mobile hero composition keeps the complete crane, building and Total Station visible with breathing room.
- Hero text no longer touches the screen edge.
- Heading size is reduced proportionally rather than behaving like a cropped desktop heading.
- CTAs fit inside the viewport; very narrow phones stack them.
- Trust cards use a compact 2x2 grid.
- All downstream grids, cards, forms, dialogs and images collapse safely without horizontal scrolling.

## QA viewports
- 390x844 phone
- 768x1024 tablet
- 1366x768 laptop
- 1920x1080 desktop
