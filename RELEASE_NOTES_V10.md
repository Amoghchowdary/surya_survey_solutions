# Surya Survey Solutions V10

## Production responsive overhaul
V10 preserves the approved desktop visual direction and corrects scaling/cropping across phone, tablet, laptop and desktop.

### Key corrections
- Mobile no longer shows only the logo; the Surya Survey Solutions brand name remains visible.
- Header height, logo, navigation and menu controls are breakpoint-specific.
- Hero typography scales independently across four device classes.
- Phone uses the dedicated portrait hero source and controlled focal point.
- Tablet uses the dedicated tablet hero source.
- Laptop has a short-height safeguard for 1024×768 and 1366×768 class displays.
- CTA buttons cannot overflow; they stack on very narrow phones.
- Trust cards become 2×2 on phone while remaining 4 columns on tablet/laptop/desktop.
- Statistics and client-logo marquee receive responsive sizing corrections.
- Existing V9 contact details, client logos, counters, security setup and GitHub Pages workflow are preserved.
