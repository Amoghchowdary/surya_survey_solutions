# Surya Service Solution

Production website for **Surya Service Solution**, a civil-engineering surveying business.

## Website pages

- Home
- About Us
- Project Gallery
- Contact Us

## Technology

- React 19
- TanStack Start / TanStack Router
- Vite
- Tailwind CSS 4
- TypeScript

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The application source is contained in `src/`, with static assets in `public/`.
