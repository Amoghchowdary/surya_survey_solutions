# Surya Survey Solutions V7

## Homepage changes
- Added **Upcoming Projects** to the project-statistics line.
- Statistics are now five items: Total, Completed, Ongoing, Upcoming, Clients Served.
- Added **Previously Worked With** section directly below the statistics.
- Added a continuous **left-to-right** client-logo marquee.
- Logo marquee is responsive on desktop, tablet and mobile.
- Motion is disabled automatically for visitors who prefer reduced motion.

## Client logo assets
The actual customer-company logo files were not present in the supplied V6 package/current upload.
V7 therefore includes eight neutral replaceable SVG slots in:
`public/images/client-logos/`

Replace those SVG files with the actual company logos (or update `clientLogos` in `src/lib/site-data.ts`) and the marquee layout will remain unchanged. No company identities have been invented.
