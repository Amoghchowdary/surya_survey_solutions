# Surya Survey Solutions V19

## Exact client-order rebuild
- Project media rebuilt from the newly supplied client ZIP, folder by folder and media item by media item.
- Every project remains segregated in its own folder.
- Numeric filename suffix is the ordering authority.
- GAD `twenty four .jpeg` is explicitly assigned to position 24 by written-number fallback because its filename contains no numeric suffix.
- GAD `fifty 50.pdf` is rendered as the visible media item at position 50 instead of being dropped.
- Videos stay in the exact numbered slot among images.
- Every media tile displays a title card with three-digit sequence and exact source filename.
- Source-number gaps are preserved, never auto-renumbered.

## Brand protection
- Project images are web-optimized and have the Surya Survey Solutions logo + `™` watermark baked into the displayed file.
- Video playback uses the same Surya Survey Solutions logo + `™` overlay.
- Existing no-download UI deterrents, context-menu blocking and drag blocking are retained.
